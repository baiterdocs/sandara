# WhatsApp Business de Sandara: textos listos para pegar

Dónde se cargan (celular o app de escritorio): **Herramientas para la empresa**.
En WhatsApp, `*texto*` sale en negrita y `_texto_` en cursiva.

---

## Mensaje de bienvenida

```
Hola, bienvenida a Sandara ✨
Gracias por escribirnos. En unos minutos te atendemos.
Mientras tanto, puedes ver la colección en sandara.pe
¿Buscas algo para ti o un regalo?
```

## Mensaje de ausencia

Programarlo en «Fuera del horario comercial» (primero poner el horario real en el perfil de empresa).

```
Gracias por escribir a Sandara ✨
En este momento estamos fuera de horario, pero te responderemos apenas abramos.
Si nos cuentas qué pieza te interesa, te preparamos la información.
```

## Respuestas rápidas

El atajo se escribe sin barra al crearla. En el chat se usa con `/atajo`.

### hola

```
¡Hola! Te saluda Sandara ✨
Con gusto te ayudo. ¿Buscas una joya para ti o un regalo para alguien especial?
```
